# Full Stack Blog Application

## About

A Full Stack Blog Application that allows users to register, login, create, read, update and delete blog posts.

## Features

- User Registration
- User Login
- JWT Authentication
- Dashboard
- Create Blog
- Read Blog
- Update Blog
- Delete Blog
- Blog Details
- User Profile
- Logout
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
